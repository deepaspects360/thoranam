Invite generator

[Demo] Engagement: make a personal link and WhatsApp message for every guest.

1. Where is the invitation hosted?

The address Netlify or GitHub Pages gives you after you upload the exported folder. Links in step 3 are built from it.

2. Guests

Name, then an optional WhatsApp number after a comma. Paste straight from a spreadsheet too.

3. Personal links

Your links will appear here.

How to put the invitation online

  1. Netlify: open app.netlify.com/drop, drag the exported folder in. You get an address like name.netlify.app.
  2. GitHub Pages: create a repository, upload the folder's files, then Settings → Pages → deploy from the main branch.
  3. Paste that address in step 1 and generate links. Each guest opens a page that greets them by name.
