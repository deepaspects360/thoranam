Your invitation website: demo-other-celebration-20
=====================================

1. Upload this whole folder to a static host. Both are free:
   - Netlify: open https://app.netlify.com/drop and drag this folder onto the page.
   - GitHub Pages: put these files in a repository, then Settings > Pages > deploy from the main branch.
2. Open the address the host gives you. Pages in this folder: index.html, ta.html, hi.html.
3. Open invite-generator.html on your computer to make a personal link, WhatsApp message and CSV for each guest.

Tip: after you have the address, export again with it filled in. Then search engines and link previews get the right canonical address and a sitemap.

Notes:
- RSVP forms are removed from exported sites (there is no server to receive replies).
- Fonts, and for some designs animation libraries, load from the internet.
